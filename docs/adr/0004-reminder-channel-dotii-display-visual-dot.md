# ADR-0004: 提醒通道选型——Dotii-Display 桌面视觉提示点（路 2）

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

干预假设的核心是"私密、即时、不打断教学"。候选提醒通道：

- (a) 学生平板/桌面屏幕弹窗（每生一屏，成本高、上课分心）
- (b) 震动手环/腕带（私密即时，但成本+续航+被贴标签）
- (c) 教师仪表盘高亮（学生零成本，但失去即时性，依赖教师打断讲课）
- (d) 教室前端环境提示（非定向，霍桑效应风险）
- (e) 桌面震动垫/坐垫（私密触觉，无可穿戴）

用户初选 (b) 震动手环，并指向 GitHub 仓库 `ZeroOne000011/Dotii-Display` 作为实现。

子代理核查该仓库后确认：**Dotii-Display 是 ESP32-S3-Touch-AMOLED-1.75 圆形桌面屏 + Windows/macOS 管理中心**，**纯视觉输出**，没有震动马达/蜂鸣器/触觉器件，与 (b) 震动手环**互斥**。本地 HTTP API（`127.0.0.1:8787`）触发自定义页面/表情。仓库无显式 LICENSE 文件。

## Decision

选 **路 2**：用 Dotii-Display 当桌面视觉提示点。

- 研究问题表述从"震动手环"改为"**私密即时提醒**"以包容视觉通道
- 提醒由 Dotii-Display 圆形 AMOLED 屏亮起（自定义页面或 Dotii 表情）实现
- 通过本地 HTTP API 从姿态检测管线触发

## Consequences

- 提醒通道从触觉变视觉，"私密性"靠低调视觉（柔和 Dotii 表情）而非触觉
- 复用现有硬件（Dotii-Display 已有 v1.1.1 tag 与开发指南），集成成本最低
- 霍桑效应风险：周围同学可能看见亮屏——通过低调 Dotii 表情 + 物理视野限定被试座位区缓解
- **复用前需联系作者（ZeroOne000011）确认授权**，仓库无显式 LICENSE 文件
- 实验假设表述需相应调整：从"震动手环能否起效"改为"私密即时视觉提醒能否起效"
