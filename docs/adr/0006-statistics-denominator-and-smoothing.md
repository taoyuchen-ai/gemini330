# ADR-0006: 不良坐姿时长占比的统计口径

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

主结局指标 = "不良坐姿时长占比"。需要明确：

1. 分子与分母的精确定义
2. 最短持续时长（避免单帧抖动入统计）
3. 离座与缺失帧如何处理
4. 统计口径与提醒触发逻辑（30 秒持续）的关系——是否一致？

ADR-0005 已定单帧分类后用 1 秒窗移动众数平滑。本 ADR 决定占比公式与异常帧处理。

## Decision

**占比公式**：

```
不良坐姿时长占比 = (平滑后判为趴桌+弯腰的帧数) / (总有效帧数 − 离座帧数 − 缺失帧数)
```

**关键约定**：

- **分母**：剔除离座帧与缺失帧，反映"净学习时段"的不良占比
- **离座帧**：连续 30 秒无骨架检测到的时段，按 ADR-0007 标记为离座状态
- **缺失帧**：相机掉线、MediaPipe 推理超时等异常产生的帧，按 ADR-0007 处理
- **不插值**：缺失帧不通过插值填补，避免伪造数据
- **统计口径与提醒触发逻辑解耦**：提醒用 30 秒持续阈值（ADR-0007 干预决策），统计反映真实不良时长（含未触发提醒的短时不良）

## Consequences

- 报告中的"不良坐姿时长占比"是经平滑与剔除后的"净学习时段占比"，与原始帧数比口径不同
- 提醒触发 30 秒阈值与统计口径解耦，可独立调整
- 短时不良（< 30 秒）虽不触发提醒，但仍计入统计——这反映真实不良时长，与干预机制设计一致
- 跨被试、跨阶段对比需用同一分母定义，避免口径漂移
- 缺失帧过多（如 > 20%）的会话整体剔除，不入分析
