# ADR-0002: Gemini335 深度流用于头-桌面距离判定，非 3D 脊柱曲率

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

MediaPipe BlazePose 只消费 RGB 流。Gemini335 的深度流可选用途：

- (a) 不用，纯当 RGB 摄像头（沉没成本，诚实承认）
- (b) 3D 脊柱矢状面曲率（侧视下比纯 2D 角度更准，但工作量翻倍且需团队深度视觉经验）
- (c) 头-桌面距离判定（区分"前倾读写"vs"趴桌"，2D 难以区分的边界情况）
- (d) 遮挡过滤 / 测距

团队**无 RGB-D 自研经验**（用户已确认）。

## Decision

选 **(c)**：用深度流判定"头-桌面距离"，区分两类姿态：

- **前倾读写**：头-桌面距离在可接受区间内 → **可接受**，不算不良
- **趴桌**：头-桌面距离低于阈值 → **不良**

走 **Orbbec 官方 SDK** 拿 aligned depth+color 流，**不自研 RGB-D 配准**。

## Consequences

- 前倾读写 vs 趴桌的区分有物理依据，避免仅靠 2D 角度误判
- 不做 3D 脊柱曲率，精度让位于工作量
- 依赖 Orbbec SDK 的 RGB-D 配准质量，需在标定阶段验证对齐精度
- 阈值（头-桌面距离的具体毫米数）需现场标定，记录于 ADR-0005
- 若 Orbbec SDK 对齐质量不达标，需回退方案（多帧中位数 + 双边滤波）
