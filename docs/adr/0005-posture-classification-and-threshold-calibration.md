# ADR-0005: 姿态分类为 6 类，阈值现场标定 + 文献参考

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

主结局指标是不良坐姿时长占比，需要明确：

1. 坐姿分为哪几类（哪些算不良、哪些算中性、哪些算良好）
2. 每类的判定依据（RGB 角度还是 RGB-D 深度）
3. 阈值如何确定

ADR-0002 已定"前倾读写 vs 趴桌"按头-桌面距离（深度）区分。RGB 角度还需分类其他姿态。用户在 Q6 确认：后仰=休息中性，转头侧身=中性。

## Decision

**6 类姿态分类**：

| 类目 | 判定依据 | 评价 |
|---|---|---|
| 坐正 | RGB 躯干竖直 + 头-桌面距离正常 | 良好（baseline） |
| 前倾读写 | 深度判定头-桌面距离在可接受区间 | 可接受 |
| 趴桌 | 深度判定头-桌面距离低于阈值 | **不良** |
| 弯腰 | RGB 躯干-大腿角或脊柱矢状角低于阈值 | **不良** |
| 后仰 | RGB 躯干后仰超过靠椅阈值 | 休息/中性 |
| 转头侧身 | 头部偏航角或躯干侧偏超过阈值 | 中性 |

**不良坐姿 = 趴桌 + 弯腰** 两类。

**阈值标定方法**：现场实测标定 + 文献参考值结合：

- 每位被试在标准姿势下采集 30 秒基线，记录各角度/距离分布
- 结合文献参考值（如躯干-大腿角 < 100° 提示弯腰，头-桌面距离 < 20 cm 提示趴桌）
- 阈值记录于独立配置文件（如 `config/thresholds.yaml`），便于跨被试调整

**单帧抖动处理**：单帧分类后用 **1 秒窗移动众数平滑**，避免单帧误判入统计。

## Consequences

- 初次部署需 ~1 周校准期，对 6 名被试逐人标定阈值
- 阈值跨被试可能不同（身高差异），需独立配置文件而非硬编码
- 单帧抖动通过 1 秒窗缓解，但短于 1 秒的快速姿态变化会被平滑掉（可接受）
- 后仰与转头侧身不计入不良，避免与"课间休息""看黑板"等正当行为混淆
- 文献参考值需在报告中引用具体来源（如 GB/T 26156 或脊柱外科学教材）
