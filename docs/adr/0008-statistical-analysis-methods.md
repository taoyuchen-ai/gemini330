# ADR-0008: 数据分析方法——Friedman + Wilcoxon 符号秩（非参数）

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

实验设计 = 6 人被试内前后测，3 阶段（基线 2 周 / 干预 4 周 / 跟踪 2 周）。主结局 = 不良坐姿时长占比（连续型）。

候选统计方法：

- (a) 重复测量 ANOVA（rm-ANOVA）——最常用，但要求球形假设与正态性
- (b) Friedman 检验 + 事后 Wilcoxon 符号秩——非参数，小样本更稳
- (c) 被试内 t 检验——简单但未校正多重比较
- (d) 贝叶斯被试内模型——小样本下报告 BF 而非 p 值

6 人样本量不符合正态假设，参数方法功效与稳健性均不足。

## Decision

**主分析**：

- **Friedman 检验** 一次性检验 3 阶段（基线/干预/跟踪）不良坐姿时长占比的差异
- 事后成对比较用 **Wilcoxon 符号秩检验**，**Bonferroni 校正**多重比较
- 报告效应量 **η²**（Kendall's W 转 η²）

**敏感性分析（可选）**：

- 贝叶斯被试内模型（如 PyMC 或 brms 拟合），报告 **Bayes Factor** 作为补充
- 用于"小样本下 p 值不显著时的证据强度判断"

**探索性分析**：

- 不良坐姿时长占比与"现有视力筛查 + 体态问卷"得分的 **Spearman 相关**
- 提醒触发后纠正耗时（秒）的描述性统计

## Consequences

- 非参数方法在 6 人小样本下功效仍偏紧，可能漏掉真实效应（Type II 错误风险）
- Bonferroni 校正进一步降低功效——这是已知代价，换取 Type I 错误控制
- 贝叶斯敏感性分析可在 p 值不显著时提供"证据强度"的第二判断
- 报告需明确披露：样本量限制、非参数方法选择理由、效应量、统计功效后验估计
- 如未来扩到 ≥12 人，可重测用 rm-ANOVA（需先验证球形假设）
