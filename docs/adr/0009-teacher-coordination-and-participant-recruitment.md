# ADR-0009: 教师配合约束与被试招募分层

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

干预假设的核心是"私密即时提醒 + 每日反馈能否减少不良坐姿"。但课堂环境中存在多重混淆变量：

- **班主任口头提醒坐姿**会引入教师中介效应，与系统提醒效应混淆
- **任课教师知情**可能改变其教学行为，间接影响学生坐姿
- **被试招募偏差**——若只招近视学生，样本不能代表全班
- **座位调整**——学校常规调座可能改变被试是否在相机视野区
- **被试中途退出**——退出本身可能是干预副效应（如被试感到被监视），需保留数据用于分析

ADR-0003 已定 6 人被试内前后测、被试座位固定在相机视野区。本 ADR 决定教师配合与被试招募细节。

## Decision

**教师配合约束**：

- **班主任签同意书**，明确"不主动口头提醒坐姿"——避免混淆干预效应
- **其他任课教师不知情**——避免教学行为改变
- 班主任可在课间与被试正常交流，但不在上课期间口头纠正坐姿

**被试招募**：

- 班主任推荐 + 学生自愿报名 + PI 面谈筛选
- **按视力状况分层**：正常视力 / 轻度近视 / 中度近视，每层 2 人
- 排除标准：重度近视（> 600°）、脊柱疾病史、严重行为问题

**座位安排**：

- 被试座位固定在相机视野区
- 学校常规调座时，PI 现场重标定相机角度与阈值
- 若被试被调出视野区，优先协调保留座位；不可保留则该被试数据中断，进入退出者分析

**退出流程**：

- 被试或家长随时可撤回同意，无需理由
- 退出者已采集数据**保留用于"退出者分析"**——退出本身可能是干预副效应
- 删除可识别信息（姓名、学号），保留匿名坐标
- 家长明确撤回同意则**一并删除所有该被试数据**

## Consequences

- 教师中介效应被控制，干预效应归因更清晰
- 视力分层招募保证样本代表性，便于事后探索"近视程度是否影响干预效应"
- 退出者分析作为干预副效应的间接证据——若退出者集中在某层（如中度近视），提示该层干预不耐受
- 学校调座是常见干扰源，PI 需与班主任建立协调机制
- 报告"方法"章节需透明披露教师配合约束，避免读者误判为"自然课堂"
