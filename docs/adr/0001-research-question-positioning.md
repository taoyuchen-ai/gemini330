# ADR-0001: 研究问题定位为不良坐姿时长占比，而非视力/脊柱健康结局

- **Status**: Accepted
- **Date**: 2026-10-01

## Context

原始课题描述同时提出两个目标：
1. "坐姿对视力与脊柱的影响"——长期健康结局
2. "实时提醒+每日反馈能否减少不良坐姿"——行为结局

二者性质不同：
- 视力变化需数年观察，本系统测量周期（基线 2 周 + 干预 4 周 + 跟踪 2 周）远不足以观测到视力变化
- 脊柱侧弯无法从坐姿摄像头测量，需 Adam 前屈试验或 X 光，超出本系统能力
- 若主研究问题写成 (1)，方法论无法兑现，报告与建议书的论证会自相矛盾

## Decision

主研究问题 = **"实时提醒 + 每日反馈能否显著降低中学生在校不良坐姿时长占比"**。

次级/探索问题 = 不良坐姿时长占比与现有视力筛查 + 体态问卷得分的相关性（**不声称因果**）。

视力变化与脊柱侧弯**不作为本系统的可测量结局**。

## Consequences

- 报告与建议书论证框架以行为结局（不良坐姿时长占比）为主轴
- 视力/脊柱数据走"现状相关性"路径，使用学校现有筛查数据做关联分析
- 长期健康结局（视力退化、脊柱侧弯进展）需后续独立纵向研究
- "建议书"部分可基于行为结局推论"长期潜在健康影响"，但措辞为"建议"而非"已证实"
